# OWEM - Open Wiki of Electrochemical Methods

This repository contains the source code and workflows that are required to serve the [OWEM website](https://owem-wiki.github.io).

Edits to the wiki content should be made in its repository: [owem-wiki/owem-source](https://github.com/owem-wiki/owem-source).

The website is built using the [Just the Docs](https://just-the-docs.github.io/just-the-docs/) template for [Jekyll](https://jekyllrb.com/)
